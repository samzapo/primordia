# Revision 67 — Instinct and division controls

Owner direction, October18,2026. Experimental first, preserving both saved ponds.

Instinct is a local saved display toggle in the nucleus, enabled by default. It shows/hides the
current intention in the existing bottom information strip and its direction
arrow on the selected living cell. Hover/build information and important notices
keep priority. It does not change sensing, navigation, ATP, RNG or autonomous AI.

Wave crests are the initial display for this update, including one guarded
upgrade of older saved preferences. Later deliberate Streamlines/Wave crests
choices are remembered normally. Other saved display/audio settings remain.

The bud's Divide button opens a menu with Auto divide, Start division now and
Back. Auto divide toggles continuous division for this cell. Start division now
commits an already-ready paid birth or saves one pending request. It supersedes
continuous auto for that body. The Divide entry remains highlighted while a
request or continuous mode is active, with the existing readiness ring.

A pending one-shot can be cancelled in the same menu. It waits for existing
resource funding, safe placement and the pond population gate, without granting
resources/AP. A successful committed birth clears only the parent's one-shot;
the daughter never inherits a request. Parent/daughter each receive the existing
one AP. Failure/blocked retries leave the request armed. Continuous policy and
its existing explicit family API remain available; the new simple menu is per cell.

The request is an allowlisted, authenticated, sequenced command and a saved
per-cell flag, exposed in authoritative division readiness. Duplicate delivery
returns the original receipt and cannot re-arm a fulfilled request. Old cells
default to no request; no pond reset or anatomy migration is needed.

Use actual desktop/touch pointer input and hardware pixels for the toggle,

Gameplay and Mechanics and experimental-only player notices current.
